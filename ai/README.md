# AI workspace tools

| Folder or file | Purpose |
|---|---|
| `workspaces/` | Discover code, prepare task context, and validate scoped workspaces. |
| `workspaces.json` | Define component ownership and task checks. |
| `tests/` | Test discovery, hooks, sparse workspaces, and model planning contracts. |
| `guides/` | Explain writing rules and workspace commands. |
| `fixtures/` | Store context discovery evaluation cases. |
| `benchmarks/` | Measure context discovery behavior. |
| `research/` | Retain historical AI tooling evidence. |

Root `AGENTS.md` remains the shared instruction entry point.
Codex, Claude, Gemini, and GitHub retain their required small discovery files.
Their commands point to this folder.
