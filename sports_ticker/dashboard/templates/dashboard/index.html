04 / HARDWARE

Built out of panels, not pixels

Six 64×32 HUB75 RGB LED panels chained into a single 384×32 surface. A Raspberry Pi drives the matrix over a bonnet and runs the controller, which asks the backend what to draw and then composites the frame locally.

The backend is a Flask server on an Ubuntu VPS. It polls ESPN, OpenF1, market and weather APIs on independent schedules, keeps a snapshot per mode, and hands the controller a pre-shaped payload so the Pi never has to parse a scoreboard feed itself.

Everything on this page — the board above included — comes from the same renderer that drives the physical panel. Nothing here is a mockup.
